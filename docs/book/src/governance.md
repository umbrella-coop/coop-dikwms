# Governance

- **Spec Intake Rule** — specs are promoted from the backlog, never created on demand
- **Roadmap Protection** — user inputs: record -> roadmap-fit brainstorm -> P1-P3 + deps -> delta ops
- **Delta operations** — implemented specs evolve via ADDED/MODIFIED/REMOVED sections
- **Schemaless philosophy** — warn-not-fail at the API boundary
